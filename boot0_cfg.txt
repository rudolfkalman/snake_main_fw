STM32G4 オプションバイト書き換え完全シーケンス
STEP 1: 外扉の解錠（Flash全体のロック解除）
まずは FLASH_CR をいじれるようにします。

set *0x40022008 = 0x45670123
set *0x40022008 = 0xCDEF89AB

STEP 2: 内扉の解錠（Option Bytesのロック解除）
これで FLASH_OPTR（性格設定）が書き換え可能になります。

set *0x4002200C = 0x08192A3B
set *0x4002200C = 0x4C5D6E7F

STEP 3: ロック解除の確認
値が 0x00000000（または 31bit と 30bit が 0 ）になれば成功です。

x/xw 0x40022014

STEP 4: 新しい性格をセット（下書き）
PB8 を無視する設定値（nSWBOOT0=0）を書き込みます。

set *0x40022020 = 0xfbeff8aa

STEP 5: 書き込み確定（焼き付け開始）
FLASH_CR の 17 ビット目 (OPTSTRT) を立てます。これで Flash に保存されます。

set *0x40022014 |= (1 << 17)

STEP 6: 設定の適用と再起動（運命の瞬間）
FLASH_CR の 27 ビット目 (OBL_LAUNCH) を立てます。
※ここで GDB の通信が切れます。

set *0x40022014 |= (1 << 27)
